Potential Questions for In-Class Quiz

Potential Questions for In-Class Quiz

Short-answer (7–10 minutes each). Justify all claims with reference to concepts from the lecture and/or the NIST AI 100-2 taxonomy. Quantitative findings from the live-coding session are fair game as supporting evidence.

Quiz 1: PGD Evasion and Disparate Impact

Applied + Conceptual
After running the PGD evasion attack on the COMPAS logistic regression model, the lab produces the following results at ε = 1.0 (L∞ budget):

African-American FPR: 0.41 → 0.79  |  Caucasian FPR: 0.21 → 0.63  |  AIR (AA/CA): 1.95 → 1.25

Prompt: The AIR decreases as ε increases, moving closer to parity — yet both groups are worse off in absolute terms.

  • Explain why a PGD attack on a logistic regression model pushes all predicted scores upward, and why this compresses the AIR toward 1.0 rather than widening the gap.
  • Is a model that is "more fair under attack" actually safer to deploy? Distinguish between absolute harm and relative disparity in your answer.
  • Classify this attack using the NIST AI 100-2 five dimensions: system type, attack stage, attacker goal, attacker capability, and attacker knowledge.
Tip: The answer to whether the model is "safer" depends on which fairness criterion you apply. Think carefully about FPR parity vs. AIR and what each measures about harm.

Quiz 2: Data Poisoning and the Stealth Zone

Fairness + Security
The lab's label-flip poisoning loop produces the following results when targeting African-American training records (two_year_recid = 1 → 0):

Poison rate 5%: AUC = 0.713 (Δ = −0.008), AIR = 1.79
Poison rate 10%: AUC = 0.706 (Δ = −0.015), AIR = 1.52
Poison rate 15%: AUC = 0.699 (Δ = −0.022), AIR = 1.11
Poison rate 20%: AUC = 0.688 (Δ = −0.033), AIR = 0.87

Prompt: Using the results above, identify the stealth zone — the poison rate range where the attack is undetectable by standard AUC monitoring yet causes a meaningful fairness violation.

  • Define the stealth zone precisely: what are the AUC and AIR thresholds you are using, and which poison rates fall within it?
  • A PSI-based drift monitor flags features with PSI > 0.10. Would this monitor detect the attack within the stealth zone? Explain why, with reference to what PSI measures and what the poisoning attack actually changes.
  • Propose one detection control that would catch this attack. Justify why it is more effective than PSI for this attack type.
Tip: Think carefully about what label-flipping changes in the data: the feature distributions remain untouched. PSI is computed on features, not labels. Does that matter?

Quiz 3: Membership Inference and the Overfitting–Privacy Link

Privacy + Reasoning
The shadow-model membership inference pipeline produces the following results on the COMPAS GBT model:

GBT Train AUC: 0.961  |  GBT Test AUC: 0.723  |  Generalization gap: +0.238
MI AUC (shadow pipeline): 0.71
Mean confidence — training members: 0.84  |  Mean confidence — test non-members: 0.67

Prompt: Interpret the MI AUC of 0.71 in the context of the COMPAS deployment scenario.

  • Explain mechanistically why a large generalization gap produces a high MI AUC. What property of overfit models does the shadow pipeline exploit?
  • If this model were deployed by a county probation office with a public API, what specific information could a journalist extract using this attack? Be precise about what "membership" reveals in this context.
  • A colleague proposes adding L2 regularization to reduce the generalization gap. Would this also reduce the MI AUC? Explain the mechanism, and identify one tradeoff it introduces.
Tip: MI AUC = 0.50 is random; MI AUC = 0.71 is moderate-to-strong leakage. Anchor your interpretation to this scale. Also recall that knowing who was in the training set for a recidivism model is different from knowing their predicted score.

Quiz 4: Model Extraction and the Value of Output Rounding

Security + Applied
The boundary-focused active querying pipeline produces the following fidelity curve when attacking the COMPAS GBT (target AUC = 0.723):

100 queries: fidelity = 0.61, substitute AUC = 0.58
400 queries: fidelity = 0.79, substitute AUC = 0.67
800 queries: fidelity = 0.88, substitute AUC = 0.71
1,500 queries: fidelity = 0.93, substitute AUC = 0.72

A defender proposes rounding API outputs to 2 decimal places. Tramèr et al. (2016) showed that output rounding increases the query budget required for high fidelity by 10–100×.

Prompt: Evaluate the boundary-focused querying strategy and the output rounding defense.

  • Explain why querying near the decision boundary (score ≈ 0.50) is more efficient than random querying for model extraction. What information does a boundary sample carry that a high-confidence sample does not?
  • If output rounding increases the required query budget by 10×, approximately how many queries would now be needed to reach 90% fidelity? Is this a sufficient defense against a well-resourced adversary? Justify your answer.
  • A 90%-fidelity substitute model still achieves an AUC within 0.003 of the target. Identify one downstream attack that becomes possible once the adversary holds a high-fidelity substitute, and explain why the substitute — rather than the target — is used to mount that attack.
Tip: The downstream attack in the third bullet is covered in the lecture slides. Think about which attack requires gradient access to the model — and which model the attacker can compute gradients on.
